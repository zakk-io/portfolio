ECG Classification API

Quantized On-Device Heartbeat Classification

  • Problem: ECG classification models need to run accurately, fast, and lean enough for resource-constrained deployment.
  • Built: An ECG classification API developed and evaluated during an AI research internship at the University of Parma.
  • Approach: Quantized the model to INT8 with TensorFlow Lite to cut inference time and footprint.
  • Result: 92.7% accuracy on 1,000 test samples with ~18ms single-image inference latency.
